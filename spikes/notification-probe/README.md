# Android 手环提醒可行性 Spike

此目录是一次性验证，不属于正式额度应用，也不读取额度、会话、任务或令牌。

## 真机结论

2026-07-23 在 Android + AstroBox + 小米手环 10 上验证失败，停止继续开发此路径：

- `system.notification.show`：设备明确显示未声明支持。
- `system.notification.postDelayedShow`：设备明确显示未声明支持。
- `system.vibrator.vibrate`：调用未抛出异常，但用户未感受到震动，不能视为可用。
- v0.0.2 探针页面存在横向溢出：页面宽度 `212px` 之外又增加了左右内边距，导致横向滑动并可能干扰侧滑退出。该 UI 缺陷不影响“通知接口不受支持”的结论。

因此，当前 Band 10 固件不能通过这套快应用 API 实现应用关闭后的系统提醒。请卸载「Codex 提醒测试」，不要把此 RPK 当成正式应用使用。

## 通过标准

在 Android + AstroBox + 小米手环 10 中，打开「Codex 提醒测试」后立即退出该应用；约 60 秒后，手环仍能显示系统通知并产生震动。

## 操作

1. 在 AstroBox 中导入 `dist/com.codex.quota.notifyprobe.debug.0.0.2.rpk`。
2. 打开手环中的「Codex 提醒测试」，先记录“前台震动”“前台通知”“延时提醒”三行状态。
3. 只有“延时提醒：已安排”才立即返回表盘，保持 AstroBox 与手环连接。
4. 在 75 秒内记录：是否弹出、是否震动、点按是否回到探针页面。

没有弹出或没有震动即为未通过；不将“应用处于前台时能看到文字”算作通过。
