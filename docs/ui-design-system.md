# CodexQuota UI 设计系统

这份规则描述 Android、Windows 和小米手环后续可以共享的视觉语言。它只定义视觉与状态语义，不改变协议、通知策略或数据边界。

## 视觉气质

克制、清晰、紧凑、专业，面向开发者工具场景。使用柔和背景层次、半透明表面、细白色描边和低强度阴影表达层级；不依赖全屏实时模糊，不使用霓虹、玻璃堆叠或大面积渐变。

## 色彩与状态

| 语义 | Android Light | Android Dark | 用途 |
| --- | --- | --- | --- |
| 主强调 | `#176FAF` | `#91C7F0` | 主要操作、导航选中、同步中 |
| 处理中 | `#1876C1` | `#8FC9F5` | 状态点、短标签、活动摘要 |
| 需要授权 | `#C5423E` | `#FFB4AB` | 需要用户回到电脑处理 |
| 等待查看 | `#198052` | `#72D6A6` | Hook Stop 后等待用户查看 |
| 已同步 | `#198052` | `#72D6A6` | 最近一次额度确认仍然有效 |
| 缓存 | `#A96E00` | `#FFC968` | 使用上一次可信数据 |
| 离线 | `#C5423E` | `#FFB4AB` | 手机无法连接电脑或手环 |
| 未知/不可用 | `#687680` | `#B3C0C5` | 尚未连接、额度缺失或状态不可用 |
| 额度危险 / 圆环红 | `#C5423E` | `#FFB4AB` | 额度低于 20% |
| 额度警告 / 圆环黄 | `#A96E00` | `#FFC968` | 额度 20–49% |
| 额度健康 / 圆环绿 | `#198052` | `#72D6A6` | 额度 50% 及以上 |

5 小时额度与周额度分别沿用同一阈值：低于 20% 为红色，20–49% 为黄色，50% 及以上为绿色。未知额度使用未知/不可用色；缓存只改变同步胶囊，不改变已知额度的阈值颜色。颜色必须同时伴随文字，不得单独传达状态。

任务状态色只用于任务前方的小圆点：处理中为蓝色、需要授权为红色、等待查看为绿色。任务标题、当前阶段和相对时间使用随明暗主题切换的中性黑白灰，不把整段文字染成状态色。

可用重置次数为 0 时使用红色，1 次及以上使用绿色，未知时使用未知/不可用色。

## 形态与间距

- 主额度卡：30dp；普通分组卡：24dp；底部导航：28dp；状态胶囊：全圆角。
- 页面水平边距约 18dp；常用间距 8、12、16、22dp。
- 细描边使用白色或主题表面高亮的低透明度；阴影保持低扩散、低透明度。
- 任务列表保持高信息密度，以轻薄表面、细分隔线和短状态胶囊组织，不把每条任务做成厚重卡片。

## 文字与图标


- 标题使用中等偏粗字重，状态与时间使用较小但保持可读的字号。
- 重要数字优先保证对比度和扫描速度，不在数字周围增加装饰性文字。
- 图标采用统一线性图标；电脑、通用 AI/对话、手环分别使用语义清楚的轮廓图标。正式产品不使用 Emoji 或字体字符作为图标。

## 动效与实现

- 状态变化可使用约 350ms 的环形 sweep、颜色和轻微透明度过渡。
- Compose 优先使用预合成的浅色表面、细描边、低强度阴影与背景渐变；它在视觉上对应原型的半透明玻璃，并避免部分设备上透明层叠加出现接缝。只有有限区域才考虑模糊。
- Android 低端设备上关闭或降级模糊后，信息层级仍必须完整成立。

## Android 深色模式

- 深色模式不是给浅色界面覆盖黑色遮罩，而是独立使用 `#10171B` 起始的蓝灰背景、`#202E34` 至
  `#2B3B42` 的三级表面，以及 `#F2F6F7` / `#B3C0C5` 两级文字颜色。
- 页面根层统一提供深色内容色；未单独指定颜色的标题、正文和分组标题不得回退为黑色。
- 卡片依靠表面明度、约 20% 的浅色细描边和低强度阴影分层，不使用高成本全屏实时模糊。
- 深色状态色使用提亮后的蓝、绿、黄、红；缓存胶囊使用黄色，离线胶囊使用红色，未知额度使用
  `#B3C0C5`。缓存中的已知额度继续按真实百分比显示红黄绿。
- 深色离线页面降低背景色彩强度，但仍保留足够的卡片边界和文字对比度；不能用整体降亮度的方式
  让标题、操作和状态一起失去可读性。

## Android 当前落地

- 首页电脑与手环状态使用一个 `76dp` 高的合并胶囊：左右等宽、内容居中、中央 `1dp` 分隔线，
  统一使用导航级 `28dp` 圆角，避免三个独立卡片挤压文字。
- 顶部同步胶囊是首页唯一的整体同步状态表达；额度卡只保留 5 小时圆环、周额度进度条和各自重置时间，
  不重复显示同步时间、数据来源或“实时”。
- 同步胶囊的相对时间由应用级时钟统一驱动，在每个整分钟自动刷新；不能依赖页面重组、
  下拉刷新或新的网络数据才更新。
- 5 小时额度圆环的百分比是卡片内唯一的最大文字；不在圆环内重复放置“剩余额度”等说明。
  数字采用约 `56sp` 的紧凑字距，数字组可作极小幅右移和上移以抵消百分号较窄、较低造成的视觉偏差，
  让数字本身成为圆心视觉重心。
- 圆环内层表面必须使用等距圆形内缩，不能通过不对称 padding 形成椭圆或造成圆环与内层错位；
  百分号独立为约主数字一半的字号并与数字底部对齐，不与数值争夺视觉重心。
- 5 小时与周额度的重置时间左对齐并使用相同辅助字号，不得与额度标题同级或争夺视觉重心。
- 顶部状态胶囊区分“电脑连接”与“额度数据新鲜度”：v3 `current` 显示“已同步”，`cached` 显示“缓存”，
  `unavailable` 显示“待同步”，电脑断开显示“离线”。“上游确认”只属于内部协议和诊断术语，
  不进入普通用户界面。
- “已同步”只允许表示一分钟内已由 Windows 上游确认的额度。Android 在运行时每 45 秒发送一次
  已认证的额度刷新请求，并每 5 秒重算数据年龄；确认时间超过 60 秒即显示“缓存”并把圆环降为灰阶。
  心跳、任务更新或单纯 WSS 在线均不能延长“已同步”。
- 动态状态胶囊必须使用受控短文案和有上限的时间单位，三端统一使用“分 / 小时 / 天 / 周”，上限为 `99周+`。组件最大宽度
  `112dp`、始终单行并保留省略兜底；不得让网络状态、错误详情或无界时间字符串直接进入胶囊。
- Android 下拉刷新必须发送已认证、绑定当前连接 ID 的额度刷新请求；不能只重连 WSS 后把同一缓存
  重新显示为刷新完成。Windows 对手机刷新请求使用 10 秒全局冷却，冷却内只回送当前快照。
- 数据为缓存或离线时，只由顶部同步胶囊表达数据新鲜度；页面背景和已知额度不整体变色。额度圆环、
  百分比和进度条始终按真实百分比显示红黄绿，例如黄色“缓存”胶囊可以与绿色“96%”同时出现。
- ChatGPT 状态卡不纳入设备状态组件：当前 Android 没有可靠的 ChatGPT 前台监控来源，
  不展示无法验证的“运行中”状态。
- 首页副标题统一为“额度与当前任务”；任务标题在达到安全显示长度时追加“...”，隐藏标题继续显示
  “任务标题已隐藏”，不泄露完整标题内容。
- Android 任务页沿用手环任务层级：每条任务左侧用红/蓝/绿彩点区分需要授权、处理中和等待查看；
  分组标题、任务状态、当前阶段和相对时间全部保持中性黑白灰。
  彩点与任务标题必须放在同一水平行并垂直居中，不能以整行高度或状态行作为对齐基准。
  `Stop` 对应的“等待查看”不是失败或终止，继续使用灰色文字；不得自行增加不存在的终止语义。
- 手机首页和任务页统一显示“状态 · 当前阶段 · 相对时间”，例如“处理中 · 执行命令 · 1分”；手环只显示
  “状态 · 相对时间”，例如“处理中 · 1分”，不显示具体工具阶段。
- 首页设备胶囊的手环半区可点击检查连接；设置页不再重复提供“检查手环连接”。设置页使用统一“连接电脑”入口，进入后可选择 App 内置扫码或输入 6 位配对码；连接页必须复用主 App 的渐变背景、`24sp` 页面标题、`14sp` 分组标题、`13sp` 正文、`10–11sp` 辅助文字、`24dp` 玻璃卡片和线性图标，不得另起一套大字号空白页面。其余入口包括隐藏任务标题、导出本地诊断和检查更新。手环日常连接由小米运动健康保持。
- 手动配对的 6 位数字使用六个真实输入位：初始焦点位于最左侧，数字逐位向右填充，当前待输入位用主题色下划线提示，不在六条横线中央叠加系统光标。连接按钮紧跟安全校验提示；键盘收起时不得贴近系统手势区，键盘弹出时保持紧凑且可触达。

## Windows 原生转译（0.4.0）

- Windows 采用托盘优先的轻量原生窗口，不复制 Android 底部导航或手机式首页；托盘菜单承担高频操作，窗口只承载配对、诊断等需要桌面空间的任务。
- 配对窗口沿用主强调色、轻描边和大圆角表面（当前正式基线圆角半径 32px），但不使用实时模糊或多层玻璃材质。二维码保持高对比和足够留白；下方直接显示 6 位配对码与 `XXXX-XXXX` 安全校验码，不要求用户展开高级信息或输入 IP 地址。配对窗口保持单实例，托盘入口只负责置前；“刷新配对码”才会生成新凭据并更新同一窗口。底部说明、有效期和两个操作按钮必须使用不相交的固定布局。
- 配对窗口常规排版只使用标题、正文、辅助文字三档；二维码、主要操作指引和 6 位配对码可作为功能焦点放大。两个操作按钮必须同高、同圆角、同字重，并使用抗锯齿边缘，不能直接暴露低精度系统圆角毛边。
- 连接与诊断窗口只显示可验证的 Windows 服务、Android 手机、同步时间和数据采集状态；“需要授权/处理中/等待查看”等任务语义仍由手机端呈现，Windows 不新增猜测性状态卡。
- Windows 的“缓存/离线”状态使用文字和灰阶辅助表达，颜色不作为唯一状态依据；撤销手机配对后的连接关闭属于连接状态反馈，不改变协议或业务语义。
- 主程序 EXE、安装/卸载界面、开始菜单快捷方式和托盘统一使用项目图标；发布构建必须检查 PE 图标资源，不能只在运行时加载托盘图标。
