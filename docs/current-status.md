# CodexQuota 当前状态

更新时间：2026-08-04。

## 当前版本

当前正式产品版本为 `0.6.2`；Android 与手环内部安装序号均为 `604`，用于在不丢失本地数据的情况下覆盖此前版本。三端自动验证和真机验收均已通过。

`0.6.2` 在 `0.6.1` 的手环连接修复基础上，统一同步、额度、重置与任务状态颜色；手机任务页补齐安全阶段摘要；手环任务页只显示状态和时间，并修复混合中英文标题截断后泄漏第二行字符的问题。Windows 安装包改为静态运行库构建，并在最小系统 PATH 下执行独立启动检查。

## 当前能力

| 组件 | 已验证能力 |
| --- | --- |
| Windows | 托盘、二维码配对、额度确认、任务 Hook、加密局域网同步和连接诊断 |
| 安卓手机 | 5 小时额度、周额度、任务看板、缓存状态、手环桥接、断线重连和检查更新 |
| 小米手环 10 | 两页纵向 swiper、5 小时额度、周额度进度条、可用重置和任务页 |

## 产品边界

- 仅支持安卓手机；AstroBox 只用于侧载或升级手环 RPK。
- 只同步额度摘要、重置摘要、连接状态、同步时间、短任务标题和任务状态。
- 不读取或传输提示词、回复、命令、文件路径、Cookie、密码或令牌。
- `等待查看` 只表示当前一轮停止并等待用户查看，不表示成功或失败。
