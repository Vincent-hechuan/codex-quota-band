# CodexQuota 当前状态

更新时间：2026-07-31。

## 当前版本

当前正式产品版本为 `0.6.1`；Android 内部安装序号为 `602`，仅用于在不丢失本地数据的情况下覆盖此前候选。`0.6.0` 为上一正式版本。

`0.6.1` 修复了 Android 手机在 Wearable 链路短暂中断后仍显示手环已连接、但实际消息监听没有恢复的问题，并保证只有最新一次 Wearable 刷新能更新手机 UI；小米服务短暂滞后时会有限重试连接查询，避免手环实际已连接却被旧回调显示为未连接。

## 当前能力

| 组件 | 已验证能力 |
| --- | --- |
| Windows | 托盘、二维码配对、额度确认、任务 Hook、加密局域网同步和连接诊断 |
| 安卓手机 | 5 小时额度、周额度、任务看板、缓存状态、手环桥接、断线重连和检查更新 |
| 小米手环 10 | 两页纵向 swiper、5 小时额度、周额度进度条、可用重置和任务页 |

## 产品边界

- 仅支持安卓手机；AstroBox 只用于侧载或升级手环 RPK。
- 只同步额度摘要、重置摘要、连接状态、同步时间、短任务标题和任务状态。
- 不读取或传输提示词、回复、命令、文件路径、Cookie、密码或令牌。
- `等待查看` 只表示当前一轮停止并等待用户查看，不表示成功或失败。
