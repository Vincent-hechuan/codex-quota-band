# 真机验收摘要

本文件是公开的验收结论，不记录个人设备编号、局域网信息、临时路径或逐次试装过程。

## 0.6.4 已确认项目

- Windows 安装包可在没有 Rust、LLVM 或其他开发环境运行库的普通 Windows 10/11 x64 环境中启动。
- Windows 托盘右键菜单正确显示 5 小时额度与周额度。
- 手机同步胶囊、额度、可用重置和任务圆点符合统一颜色语义；浅色与深色主题下文字均可读。
- 手机首页和任务页均显示“状态 · 安全阶段 · 相对时间”，不显示命令、参数、路径或日志。
- 手环只显示任务状态和相对时间；中英文混排长标题单行省略，不再泄漏被裁切字符。
- 手机与手环连接状态、缓存/离线相对时间和两页纵向滑动保持正常。
- Windows 每 45 秒独立确认官方额度；手机停止 52 秒后仍能完成下一次确认。
- 手机和手环共用最近一次官方确认时间，两分钟内显示“已同步”，不会把旧缓存刚到达手环的时间显示成“刚刚”。
- App 内置二维码扫描、6 位配对码、安全校验码和 Windows 单实例配对窗口均已完成真机联动检查。

以上项目已于 2026-08-13 完成三端联动验收；`0.6.4` 已正式发布。

## 0.6.1 已确认项目

- Windows 程序可安装、启动并显示托盘入口。
- 手机可以扫码配对并同步额度、任务和连接状态。
- 缺失 5 小时额度时，手机和手环显示 `-- / 暂无数据`，不会猜测数据。
- 有 5 小时额度时，手机与手环均可正确显示百分比、重置时间和颜色。
- 手机锁屏后会明确降级为缓存；开启自启动和电池不受限后可提高后台同步稳定性。
- 手环可以接收额度摘要和任务提醒；首页与任务页可通过原生纵向 swiper 切换。
- 周额度进度条与百分比使用一致的红 / 黄 / 绿状态色。
- 设置页的检查更新只在用户确认后打开 GitHub，不会自动下载或安装。
- 手机与手环短暂断开后，恢复连接时会重新建立消息监听；无需重启手机应用即可继续同步。

## 仍需理解的系统限制

- 安卓系统可能结束后台应用，因此不能承诺同步或通知必达。
- 手环日常连接由「小米运动健康」保持；AstroBox 仅用于安装或升级 RPK。
- 手机和电脑需要处于同一个局域网。

`0.6.1` 的手环断线重连补丁已通过断开蓝牙、恢复连接并直接打开手环应用的真机验收。
