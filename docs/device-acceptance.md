# 真机验收摘要

本文件是公开的验收结论，不记录个人设备编号、局域网信息、临时路径或逐次试装过程。

## 0.6.0 已确认项目

- Windows 程序可安装、启动并显示托盘入口。
- 手机可以扫码配对并同步额度、任务和连接状态。
- 缺失 5 小时额度时，手机和手环显示 `-- / 暂无数据`，不会猜测数据。
- 有 5 小时额度时，手机与手环均可正确显示百分比、重置时间和颜色。
- 手机锁屏后会明确降级为缓存；开启自启动和电池不受限后可提高后台同步稳定性。
- 手环可以接收额度摘要和任务提醒；首页与任务页可通过原生纵向 swiper 切换。
- 周额度进度条与百分比使用一致的红 / 黄 / 绿状态色。
- 设置页的检查更新只在用户确认后打开 GitHub，不会自动下载或安装。

## 仍需理解的系统限制

- 安卓系统可能结束后台应用，因此不能承诺同步或通知必达。
- 手环日常连接由「小米运动健康」保持；AstroBox 仅用于安装或升级 RPK。
- 手机和电脑需要处于同一个可信局域网。

本版本已通过上述真机验收，但提交、推送和发布仍需要维护者单独授权。
